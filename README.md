# 설문 집계기

엑셀에서 머리글 줄까지 복사해 붙여넣으면 문항별 결과 표(문항 / 유효 응답 / 평균 / 빈 응답 / 제외)를 보여 주는 한 파일짜리 페이지입니다.

## 쓰는 법
1. `index.html`을 브라우저로 엽니다(GitHub Pages로 올려도 됩니다).
2. 엑셀에서 머리글 줄을 포함해 범위를 복사한 뒤 입력창에 붙여넣습니다.
3. 결과 표가 바로 나옵니다.

외부 라이브러리·외부 글꼴·분석 도구를 쓰지 않고, 붙여넣은 데이터는 브라우저 밖으로 보내거나 저장하지 않습니다. 페이지의 Content-Security-Policy가 외부 연결도 막습니다.

## 집계 규칙
- 첫 줄은 머리글, 첫 열(응답번호)은 집계하지 않습니다.
- 앞뒤 공백을 지운 값이 `1`·`2`·`3`·`4`·`5` 중 하나면 유효, 비었거나 공백만 있으면 빈 응답, 그 밖은 제외입니다.
- 칸 수가 머리글보다 모자란 줄은 모자란 칸을 빈 응답으로 셉니다. 머리글보다 많은 칸은 무시합니다.
- 평균은 유효 응답의 합 ÷ 유효 응답 수를 소수 셋째 자리에서 반올림해 둘째 자리까지 보여 줍니다. 유효 응답이 없으면 `-`입니다.
- 완전히 빈 줄은 응답 줄로 치지 않습니다.

자세한 설계는 [PLAN.md](PLAN.md)에 있습니다.

## 구조와 시험
- 계산 로직은 `index.html`의 `<script id="tally-core">` 블록에 있고 화면(DOM)에 손대지 않습니다.
- `test/tally.test.js`가 그 블록만 꺼내 Node에서 시험합니다. 의존성은 없습니다(Node 18 이상).

```bash
npm test
```
